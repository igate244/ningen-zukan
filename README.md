# 人間図鑑

人との関係・つながり・特徴を記録して、人間関係を整理し、良くしていくための個人用アプリ。

- スマホのブラウザで開いて「ホーム画面に追加」すればアプリとして使える（PWA）
- **サーバーなし。** データは端末の中と、つないだ場合は**自分の Google ドライブ**（「人間図鑑」フォルダ）にだけ保存される。アプリの作者にも見えない
- ドライブへの権限は `drive.file`（このアプリが作ったファイルだけ）

## 機能（v0.1）

- 人物：写真、よみがな、区分、タグ、所属・役職・異動履歴、誕生日、出会い、連絡先、メモ
- 取扱説明書：喜ぶこと、地雷、話題、価値観、仕事の取説（報告の好み・連絡手段・つかまる時間・評価軸・強み）、学んだこと
- 次に話すこと（チェックリスト）、貸し借り・頼まれごと
- 交流ログ：会った・話した・打ち合わせ・助けてもらった など。最終交流日・ご無沙汰順
- つながり：親子・配偶者・兄弟・上司部下・同僚・友人・紹介
- 組織：会社 → 部署ごとに一覧（上司が上）
- 書き出し / 読み込み（JSON）、MYME のバックアップからの取り込み

## 開発

```bash
npm install
npm run dev     # http://localhost:5173
npm run build   # dist/ に出力
```

main に push すると GitHub Actions が GitHub Pages に公開する。

Google ドライブ連携には `src/config.ts` の `GOOGLE_CLIENT_ID` に OAuth クライアント ID を入れる。

## 構成

```
src/
  model.ts    データの形
  db.ts       端末内保存（IndexedDB）
  store.ts    全データをメモリに持ち、変更を保存・通知
  drive.ts    Google ログインとドライブ API
  sync.ts     端末 ⇄ ドライブ同期（レコード単位で新しい方を採用）
  image.ts    写真の縮小と表示
  ui/         画面
```
